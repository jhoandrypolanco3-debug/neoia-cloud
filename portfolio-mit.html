PROJECT 01 • COMPETITION ROBOTICS

BIOBUZZ 24096: Competition Chassis & Subsystems

FIRST Tech Challenge

Lead programmer and systems designer for FTC Team BIOBUZZ 24096. Built a comprehensive competition-ready software stack focusing on driver precision, deterministic autonomous scoring, and rapid sensor feedback.

Mecanum Holonomic Kinematics with Dynamic Normalization

Implemented 4-wheel omnidirectional drive kinematics with instantaneous denominator scaling: max(1.0, |y| + |x| + |rx|). This eliminates motor saturation during diagonal translation combined with angular velocity, preventing trajectory drift.

Computer Vision Auto-Aim with Limelight 3A

Integrated 100 Hz AprilTag detection pipeline. Proportional steering feedback loop (turn = tx * 0.035) allows the robot to lock onto targets automatically when the driver pulls the left trigger.

High-Frequency Velocity PID Launch System

Controlled via DcMotorEx.setVelocity(1200) with closed-loop encoder feedback. Maintains launch velocity within ±2% variance even as the 12V competition battery drops under load.

TeleOpBioBuzzTeam.java
Java • FTC SDK 
@TeleOp(name = "BIOBUZZ 24096: TeleOp Principal")
public class TeleOpBioBuzzTeam extends LinearOpMode {
  // Limelight 3A Vision Assisted Aiming
  if (gamepad1.left_trigger > 0.3 && limelight.isTargetVisible()) {
    rx = limelight.getAutoAimTurnPower(); // Kp = 0.035
  }

  // Mecanum Kinematics with Denominator Normalization
  double denom = Math.max(Math.abs(y) + Math.abs(x) + Math.abs(rx), 1.0);
  frontLeft.setPower((y + x + rx) / denom);
  backLeft.setPower((y - x + rx) / denom);
  frontRight.setPower((y - x - rx) / denom);
  backRight.setPower((y + x - rx) / denom);

  // Closed-Loop Encoder Shooter Velocity (PID)
  if (shooterActive) {
    shooterMotor.setVelocity(1200.0); // ticks/s
  }
}
