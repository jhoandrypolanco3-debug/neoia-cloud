# NeoIA — Asistente de IA para FTC y robótica

**Web oficial: https://neoia-351a.onrender.com/**

NeoIA es un asistente de inteligencia artificial pensado para equipos de
**FIRST Tech Challenge (FTC)**. Escribe y depura código Java, busca información
en internet, responde dudas de hardware y genera imágenes.

Desarrollado por el equipo **BIOBUZZ 24096**.

## Qué puedes hacer

- Generar OpModes completos (`@TeleOp`, `@Autonomous`) listos para pegar en Android Studio
- Corregir errores típicos de FTC (`Unable to find device`, `Cannot resolve symbol`, `OpMode not found`)
- Calcular chasis mecanum, encoders, `COUNTS_PER_CM` y trayectorias con IMU
- Buscar información actual en internet
- Crear imágenes con IA
